# GazeAwake v0.1.0 — Experimental Proof of Concept

GazeAwake v0.1.0 is the first public proof-of-concept release of a native Swift macOS menu bar agent that estimates coarse screen attention and connects it to display power behavior.

## Highlights

- Local AVFoundation + Vision attention heuristic
- No third-party model, package, Python, OpenCV, analytics, or network service
- No frame recording, caching by the app, or upload
- Wake display when confirmed attention returns
- Keep display awake while confirmed attention remains
- Restore normal idle behavior when the user looks away
- Local callback and distributed notification integration
- Menu bar pause/resume and wake-behavior toggle
- macOS 13+, Apple Silicon and Intel build support

## Experimental limitations

This release is not precise eye tracking. When pupil landmarks are unavailable, it falls back to a face/head-orientation heuristic. It cannot wake a fully sleeping or closed-lid Mac and cannot bypass authentication.

The current landmark mode is resource-intensive. On the documented Apple M5 test machine, active physical footprint was approximately 207 MiB, peak physical footprint approximately 292 MiB, and short CPU samples approximately 21–27%. These measurements are disclosed rather than marketed as lightweight performance.
